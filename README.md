# SubWeather 🚇🌧️

**날씨 기반 서울 지하철 이용 패턴 분석 대시보드**

> 강수량, 기온, 습도 등 기상 데이터와 지하철 이용 데이터를 연결해 **날씨에 따른 지하철 이용 패턴의 변화**를 시각화합니다.

🔗 **Live Demo:** https://subweather.streamlit.app

---

## ✨ 주요 기능

### 📊 **개요 탭**
- 평균 이용량, 날씨별 증감률, 출퇴근 쏠림도 등 핵심 지표
- **노선별 색상 구분된 서울 지하철 노선도**
- 이용량에 따라 버블 크기 변화 (대역일수록 큼)

### 🌧️ **강수량 분석**
- 강수량 vs 지하철 이용량의 산점도
- 비가 오는 날씨 영향도 분석

### 🚆 **노선/역 분석**
- 호선별 이용량 비교 (막대 차트)
- 상위/하위 역 순위 (Top 10 / Bottom 10)

### 📅 **시간/요일 분석**
- 평일 vs 주말 시간대별 이용 패턴
- 출근/퇴근 피크 시간대 비교

### 🎊 **특수 분석**
- 휴가철 영향도
- 혼잡도 통계 (1~9호선)

## 📈 데이터 구성

### 수집 데이터 (2025년 7월~12월)
- **기상 데이터**: 기온, 강수량, 습도, 풍속
- **지하철 이용 데이터**: 20개 주요 역 시간별 승하차 현황
- **혼잡도 데이터**: 1~9호선 요일/시간대별 혼잡도

### 데이터 처리
1. 시간대별 묶음: 새벽(00~06) / 출근(06~10) / 낮(10~17) / 퇴근(17~21) / 저녁(21~24)
2. 날씨 분류: 맑음 / 비 / 폭염 / 한파
3. 역-기상소 매칭: Haversine 거리 기반

## 🚀 시작하기

### 1. 로컬 실행
```bash
git clone https://github.com/Jenny5789/SubWeather.git
cd SubWeather

# 환경 설정
pip install -r requirements.txt

# .env 파일 생성 (선택사항)
# KMA_API_HUB_KEY=<API_KEY>

# 실행
streamlit run dashboard/app.py
```

### 2. 온라인 접속
https://subweather.streamlit.app

## 🎨 시각화 특징

- **노선별 색상**: 1호선 파란색, 2호선 초록색, 3호선 주황색 등
