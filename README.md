# SubWeather 🚇🌧️

**데이터 시각화로 날씨와 지하철의 숨겨진 관계를 표현하는 대시보드**

이 프로젝트는 기상 데이터와 지하철 이용 데이터를 연결하여 **다양한 시각화 기법**으로 인사이트를 도출합니다.

🔗 **Live Demo:** https://subweather.streamlit.app
📌 **GitHub:** https://github.com/Jenny5789/SubWeather

## 🎨 핵심: 데이터 시각화

이 프로젝트가 보여주는 것:

✨ **지리 정보 시각화** (Folium)
- 노선별 색상으로 구분된 서울 지하철 노선도
- 이용량에 따라 동적으로 변하는 버블 마커
- 노선별 연결선으로 전체 네트워크 표현

📊 **통계 차트 시각화** (Plotly)
- 산점도로 강수량과 이용량의 관계 분석
- 막대 차트로 호선별 이용 차이 비교
- 라인 차트로 평일/주말 패턴 대조

📈 **시계열 데이터 시각화**
- 시간대별 변화를 연속성 있게 표현
- 요일 비교를 통한 패턴 인식

---

## 📊 주요 분석 결과

### 1. 강수량이 이용량에 미치는 영향
- 비가 오는 날씨에 이용량 **-4.5%** 감소
- 출퇴근 시간대가 가장 민감하게 반응

### 2. 출퇴근 시간대 집중도
- 평일 출퇴근 시간(7-9시, 18-20시)에 **57.9%** 이용 집중
- 주말 대비 **3배 이상** 변동성

### 3. 호선별 특성
- **2호선(순환선)**: 가장 높은 일일 이용량
- **1호선**: 출퇴근 시간대 최고조
- **6호선**: 상대적으로 안정적인 이용 패턴

## ✨ 주요 기능

### 📊 개요 탭
- 핵심 지표 카드 (평균 이용량, 날씨 영향도 등)
- 대시보드의 중심: **인터랙티브 노선도 지도**
- 노선별 색상 + 이용량 기반 버블 크기

### 🌧️ 강수량 분석
- **산점도**: 강수량(X축) vs 이용량(Y축) 분포
- 상관관계 시각화로 인사이트 도출

### 🚆 노선/역 분석
- **막대 차트**: 호선별 이용량 비교
- **데이터 테이블**: Top 10 / Bottom 10 역 순위

### 📅 시간/요일 분석
- **라인 차트**: 평일과 주말의 시간대별 패턴 비교
- 출근/퇴근 피크 시간 명확하게 표현

### 🎊 특수 분석
- 휴가절 영향도 분석
- 호선별 혼잡도 통계

## 🛠️ 기술 스택

### 백엔드
- **Streamlit**: 인터랙티브 대시보드 프레임워크
- **Pandas**: 데이터 처리 및 집계
- **NumPy**: 수치 계산

### 시각화
- **Plotly Express**: 인터랙티브 차트 (산점도, 막대, 라인)
- **Folium**: 지리 정보 시각화 (지도, 마커, 연결선)
- **Streamlit-Folium**: Streamlit과의 통합

### 데이터
- **KMA 기상청 API**: 기상 데이터
- **서울 공개 데이터**: 지하철 혼잡도

## 📈 데이터 처리

### 1. 시간대별 집계
```
새벽(00~06) / 출근(06~10) / 낮(10~17) / 퇴근(17~21) / 저녁(21~24)
```

### 2. 날씨 분류
```
맑음 / 비 / 폭염(33°C↑) / 한파(-12°C↓)
```

### 3. 역-기상소 매칭
```
Haversine 거리 공식으로 각 역의 가장 가까운 기상소 연결
```

## 🎨 시각화 기법 정리

| 차트 유형 | 용도 | 기술 |
|---------|------|------|
| **지도** | 지리적 분포 표현 | Folium + CircleMarker |
| **산점도** | 변수 간 관계 분석 | Plotly Scatter |
| **막대 차트** | 카테고리별 비교 | Plotly Bar |
| **라인 차트** | 시계열 패턴 | Plotly Line |
| **데이터 테이블** | 상세 데이터 조회 | Streamlit Dataframe |
